# 🎮 Caro - Game Tracker

Caro is a modern game tracking web application designed to help players organize their game library, monitor progress, and manage their gaming backlog in a clean and intuitive interface.

> **Project Status:** 🚧 Early Development (Initial Version)

## 🌐 Live Demo

**GitHub Pages:**  
https://yanmoralescode.github.io/caro-game-tracker/

## 📖 About

The goal of Caro is to become a personal gaming hub where users can:

- 📚 Manage their game library
- 🎯 Track game completion progress
- ⏳ Organize their backlog
- 🔍 Discover new games
- ⭐ Save favorite titles
- 👤 Build a personal gaming profile

The project is currently in its initial development stage, focusing on building the application's foundation and user interface.

## 🚀 Current Features

- Responsive UI
- Modern dark theme
- TypeScript + React + Vite architecture
- Tailwind CSS styling
- GitHub Pages deployment

## 🛠️ Built With

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Lucide React

## ⚙️ Getting Started

Clone the repository:

```bash
git clone https://github.com/yanmoralescode/caro-game-tracker.git
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
